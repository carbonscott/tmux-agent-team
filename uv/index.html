Trade-offs

  • uv is now required; python3 is not. setup.sh stops with "missing: uv" before it creates anything.
  • Boss commands change from python3 harness/x.py to harness/py harness/x.py.
  • When uv has to download a Python it adds about 107 MB under tools/python. With a system Python of 3.10 or newer, uv reuses it and adds nothing.
  • uv is never called inside an agent sandbox: agents have no network, so everything is prepared in setup.

Not covered

  • A machine that truly has no Python installed was not available. The nearest thing was run: only-managed makes uv ignore the system Python, and the trap test makes any bare python3 call fail.
  • On such a machine the three checks at the top of setup.sh make uv fetch a Python into uv's own cache before tools/python gets its copy. Not measured.
  • macOS and other architectures: not run. The team needs bwrap, so Linux only, as before.
  • No screencast for this page; the evidence is the captured text above.
